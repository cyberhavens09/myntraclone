# 🛍️ Myntra Clone

A responsive **Myntra Clone Website** built using **HTML** and **CSS**.
This project recreates the basic UI of the Myntra homepage including the navbar, banners, product sections, and footer.

## 🚀 Features

* Responsive homepage design
* Modern navigation bar
* Banner section
* Product categories display
* Stylish footer
* Clean and attractive UI
* Mobile-friendly layout

## 🛠️ Technologies Used

* HTML5
* CSS3
